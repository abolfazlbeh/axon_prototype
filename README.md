# Axon

An AI-native adaptive learning platform that transforms user intent into structured, personalized, and self-improving learning experiences.

## Docs

- [`docs/v1-platform-vision.md`](docs/v1-platform-vision.md) — Product vision, architecture, and design decisions (V1)

## Concept

Axon generates structured learning curricula (chapters → slides) dynamically using a multi-agent AI pipeline. Content is stored as a platform-agnostic JSON DSL, rendered interactively, and continuously refined through behavioral feedback loops.

See the V1 doc for full detail.
